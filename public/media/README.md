# Фоновое видео

Положи сюда файл (например `bg.mp4`) и укажи путь в `src/config/site.js`:

```js
video: {
  src: '/media/bg.mp4',
  poster: '/media/bg-poster.jpg',
  overlay: 0.62,
}
```

Рекомендации:
- формат MP4 (H.264) + WebM как запасной;
- длительность 10–30 секунд, размер до ~10 МБ;
- `poster` — кадр-заглушка, пока видео не загрузилось;
- видео играет без звука, по кругу, и перекрывает весь экран (`object-fit: cover`).

Если файл не указан — сайт покажет пиксельный градиентный фон.
