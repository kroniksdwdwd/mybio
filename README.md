# mybio — мой сайт

Это мой личный сайт: витрина со всеми моими площадками, профилем Steam и музыкой.

Сайт уже работает: **[kroniksdwdwd.github.io/mybio](https://kroniksdwdwd.github.io/mybio)**

Если ты совсем не знаешь, что такое Git и терминал — тебе сюда. Ниже написано
по шагам: что нажимать, чтобы поменять текст, ссылки, музыку и картинки.

---

## Что где лежит (коротко)

| Что хочу поменять | Где это лежит |
|---|---|
| Имя, описание, аватар | `src/config/site.js` |
| Ссылки на площадки | `src/config/socials.js` |
| Музыка ( Spotify / MP3 ) | `src/config/music.js` + `src/data/localPlaylist.js` |
| Видео на фоне | `public/media/` + `src/config/site.js` |
| Картинки площадок | `public/avatars/` |

Всё это — обычные текстовые файлы. Открываешь, меняешь строчку, сохраняешь.

## Как поменять текст на сайте

1. Открой GitHub: [github.com/kroniksdwdwd/mybio](https://github.com/kroniksdwdwd/mybio)
2. Нажми на файл `src/config/site.js`
3. Нажми на карандаш (✏️) сверху справа
4. Поменяй нужные слова
5. Внизу нажми **Commit changes** → напиши любой текст → **Commit changes**
6. Подожди 1–2 минуты и обнови сайт (Ctrl+F5)

Так изменения появляются на сайте сами. Ничего устанавливать не нужно.

### Что можно поменять в `site.js`

```js
name: 'hilkach',        // имя, которое видно на сайте
tagline: 'streamer & creator',
description: 'Текст о тебе...',
```

## Как поменять ссылки (Twitch, YouTube, ...)

Файл: **`src/config/socials.js`**

```js
{
  name: 'Twitch',                      // название на карточке
  url: 'https://www.twitch.tv/3erdool',// сама ссылка
  username: '3erdool',                // подпись под названием
  icon: 'twitch',                      // иконка
  enabled: true,                       // false = спрятать карточку
  order: 10,                           // чем меньше число — тем выше
},
```

**Хочу добавить новую площадку:** скопируй любой блок, поменяй `name`, `url`,
`icon` и `enabled: true`. Карточка появится сама.

**Список иконок:** `twitch`, `discord`, `youtube`, `spotify`, `soundcloud`,
`telegram`, `twitter`, `vk`, `github`, `instagram`, `tiktok`, `reddit`, `steam`,
`mail`, `link`, `gamepad`, `globe`, `music`.

### Discord

```js
{
  name: 'Discord',
  url: 'https://discord.com/users/1221764017702440969',
  username: '1221764017702440969',
  discordId: '1221764017702440969',
  avatar: 'avatars/discord.webp',   // своя аватарка (необязательно)
  icon: 'discord',
  enabled: true,
  order: 20,
},
```

## Как поменять музыку

### Вариант 1 — свои MP3 (рекомендую)

1. Кинь MP3-файлы в папку `public/music/`
2. Кинь обложки (картинки) в `public/music/covers/` с тем же именем, что у песни
3. На компьютере выполни в папке проекта:

   ```bash
   npm install
   node scripts/build-playlist.mjs
   ```

   Скрипт сам прочитает названия и исполнителей из файлов и напишет список треков.
4. Сделай **Commit changes** — всё, новые песни заработают.

### Вариант 2 — Spotify

Файл `src/config/music.js`:

```js
spotify: {
  playlistUrl: 'https://open.spotify.com/playlist/3a0tFyXbd9BOFyt6QClD2j',
  theme: 0,
  showInPanel: true,
},
```

Кнопка со значком Spotify в плеере открывает этот плейлист.

> Честно: Spotify не даёт управлять треками из своего плеера снаружи, поэтому
> ползунок и перемотка работают только с своими MP3. Для Spotify внутри
> панели есть свой плеер.

## Как поменять фоновое видео

1. Кинь файл в `public/media/` (например `bg.mp4`)
2. В `src/config/site.js` найди:

```js
video: {
  src: '/media/bg.mp4',
  poster: '/media/bg-poster.jpg',
  overlay: 0.62,
},
```

`overlay` — насколько затемнять картинку (0 — светло, 1 — совсем темно).

## Статус «онлайн / оффлайн»

Статус берётся из твоего профиля Steam и **проверяется каждый раз, когда
кто-то открывает сайт**. Если Steam недоступен — показывается последнее
известное значение (его раз в 6 часов обновляет автоматика на GitHub).

> Discord без специального ключа не даёт проверять статус — поэтому
> статус показывается только по Steam.

## Если хочешь всё запустить у себя на компьютере

Нужен [Node.js](https://nodejs.org) (версия 20 или новее). Дальше в папке проекта:

```bash
npm install     # один раз
npm run dev     # откроется http://localhost:5173
```

Чтобы сайт обновился на GitHub после правок:

```bash
git add .
git commit -m "что поменял"
git push
```

## Частые вопросы

**Видео не грузится** → проверь, что файл называется как в `site.js` и лежит в `public/media/`.

**Песни не играют** → проверь, что MP3 лежат в `public/music/`, а в списке треков путь начинается с `music/` (без `/` в начале).

**Иконка площадки не та** → впиши правильное имя из списка выше.

**Как поменять цвет темы** → `src/styles/global.css`, блок `:root` в самом верху:
`--accent` — главный цвет, `--bg` — фон.

**Аватарки площадок обновляются сами?** → Да, раз в 12 часов скрипт на GitHub
скачивает их заново. Если добавишь площадку — картинка появится в течение суток
или запусти `node scripts/fetch-avatars.mjs` вручную.
